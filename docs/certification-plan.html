Interview gaps

What each exam fixes in your interviews

AIP-C01 · AI Engineer interviews

  • "How would you run this on AWS?" Bedrock, Knowledge Bases, Agents, Lambda, IAM.
  • RAG design trade-offs: chunking, embeddings, retrieval evaluation.
  • Guardrails, PII masking, prompt-injection defence: the governance questions banks ask.
  • Cost and latency tuning: caching, model choice, batching.
  • The micro1 lesson: talk about your own code concretely. Pair each domain with the matching part of invoice-intake-api or payment-disputes.

CKAD · both tracks

  • "How does this run in production?" Deployments, probes, resources, rollouts.
  • Config and secrets, ConfigMaps vs Secrets, service accounts.
  • Debugging a broken pod live, which is what a pairing interview looks like.
  • Helm and Kustomize basics, NetworkPolicy.

OCP Java 21 · Senior Java interviews

  • Records, sealed interfaces, switch pattern matching.
  • Virtual threads vs platform threads, structured concurrency basics.
  • Streams and collectors edge cases, Optional, generics.
  • Concurrency, immutability, equals/hashCode: the classic senior traps.
  • Lets you write "Java 21" on the CV without the honesty caveat.
How to study with Claude as your tutor

A loop that works for exams and interviews at once

  1. Map the official exam guide into a checklist (AWS and Oracle publish domain lists, CNCF publishes the CKAD curriculum).
  2. One domain a day: a Spanish "para niños" explanation, then a 20-question quiz in the real exam style, then explain your wrong answers back in English.
  3. Build, don't read: for CKAD, run every task on a local kind or minikube cluster against the clock; for AIP-C01, add a small Bedrock variant to a portfolio repo; for Java 21, write the code for every trap question.
  4. Paid mocks as the gate: Tutorials Dojo for AIP-C01, the two killer.sh sessions included with CKAD, Enthuware for OCP. Book the exam once you score 80% twice.
  5. Every Friday: a 20-minute mock interview in English on that week's domains.

Left out on purpose

Certifications not worth your money now

Scrum, SAFe, PMP, ITIL and other management credentials (you asked for the opposite, and PSM II already covers agile). Fundamentals exams such as AWS AI Practitioner or Azure AI-901 read as junior on a 15-year profile. Vendor "AI badges" from free online courses are fine to collect but carry no recruiter weight.
